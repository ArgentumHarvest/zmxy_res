# 造梦盒子实时答案面板 1.3 · 使用说明

2026-09-08 题库更新：“善见城中何人可以分解宝石？”已修正为“珍宝商人”。更新时请关闭旧面板，完整解压新下载包，再打开其中的程序。

## 一、适用范围

本工具仅适用于【造梦盒子客户端】内《造梦西游5》的“玄女的考验”答题界面，已根据造梦盒子 1.8.1 的实际截图进行适配，并由用户试用。

不适用于浏览器网页、其他客户端或其他游戏。造梦盒子后续版本如更改题框、字体或布局，也可能需要重新适配。

本工具只识别题目、显示参考答案，你需要自己选择选项、点击“下一题”；没有自动点击功能，也不需要答题快捷键。

## 二、第一次打开

1. 打开造梦盒子，进入《造梦西游5》。
2. 在本文件夹中打开 `AnswerPanel` 文件夹。
3. 双击 `AnswerPanel.exe`，出现“实时答案面板 · 1.3 问法修复版”窗口。
4. 将造梦盒子窗口缩小一点，把答案面板放在它的旁边，两个窗口不要重叠。
5. 看面板上方的下拉框是否显示造梦盒子窗口：没有找到时点击“刷新”；如果打开了多个造梦盒子窗口，请在下拉框中选择正在答题的那个。
6. 等待识别引擎准备完成，点击“开始显示答案”。
7. 在游戏里手动进入答题，面板会持续识别，显示题号、题干和答案。

> **注意**：如果使用的是压缩包，请先完整解压再打开程序，不要直接在压缩包里面运行；不要单独移动 `AnswerPanel.exe`，它旁边的 `_internal` 文件夹必须一并保留。

## 三、答题时怎么用

- 面板显示“第 3 项 / 2”时，表示当前识别结果对应第三个选项，答案文字是“2”。
- 先核对面板里的题号和题干是否与游戏当前题目一致，再自己选择答案。
- 答完后，自己点击游戏里的“下一题”，面板会继续识别，不用再次点击开始。
- 开始下一轮答题时面板也会继续工作，不需要清空记录或重置题号。
- 想临时停止，点击面板上的“暂停”；想继续，点击“开始显示答案”。
- “置顶”默认开启，让面板显示在其他窗口前面，需要时可以取消勾选。
- 不用了，直接关闭答案面板窗口即可。

识别需要时间，画面变化后可能稍有延迟。面板状态行显示的是最近一次识别结果的时间，并非游戏倒计时。

## 四、不同提示是什么意思

### 【第几项 + 答案】

题干已匹配题库，答案也能唯一对应一个识别到的选项，请核对当前题目后自行选择。

### 【题库参考 + 答案】

题干已匹配，但选项没读全、位置无法确定或文字清晰度不足。这时请按答案文字在游戏里查找，不要猜选项序号；如果同时列出多个候选答案，需要你结合题目和选项判断。

### 【请人工核对】

题干与题库没有可靠对应，可能是新题、问法不同或文字识别出错。请看面板下方的说明，相近题提示仅供参考，不代表已确认答案。

### 【等待题目】

可能尚未进入答题、正在换题、已到结算页，或暂时没有读清题目。进入正常题目页后会自动继续尝试，不必反复点击开始。

## 五、常见问题

**1. 下拉框里找不到造梦盒子**
先打开造梦盒子，再点击“刷新”。如果客户端关闭后重新打开，也需要重新刷新和选择。

**2. 提示窗口重叠**
缩小造梦盒子窗口，把面板拖到旁边，让两个窗口完全分开。面板放在左边或右边都可以，不要求固定位置。

**3. 一直等不到答案**
确认造梦盒子没有最小化、游戏画面没有被其他窗口遮住，题号、完整题干和四个选项都应可见。字太小时请适当放大游戏窗口，不要把造梦盒子放到屏幕外面。

**4. 点击面板以后还会不会识别**
会。只要窗口画面可见，切换焦点不会自动停止识别。

**5. 答案还是上一题**
等待识别更新，先核对面板题号和题干，不要照着上一题的答案选择。

**6. 数字选项或“宠物转生”题**
1.3 版保留了单个数字选项的识别补救；“宠物转生要找哪个接引人？”已与题库中的“宠物转生要找哪个NPC？”对应，答案是“公冶灵儿”。

**7. 识别不出或答案不对**
目前大部分题目测试正常，仅极少数题目存在 bug。若遇到识别不出或答案不对，请把整个电脑屏幕截下来（画面要包含这道题和面板提示），发过来并 @我排查。

**8. 想用保存的图片测试**
先暂停实时识别，等当前识别结束，再点击“用截图测试”。请选择裁剪到游戏窗口的截图，避免桌面背景占据大部分画面。图片测试只检查这一张图片，不会持续更新；继续答题时点击“开始显示答案”。

## 六、题库和数据

- 内置题库共 172 条，来自用户提供的《龙宫&教师节&元宵节问答答案.docx》，并补充了已确认的问法。
- 题库并非当前游戏全部题目的保证，也未逐题核验所有版本中的答案；只对已确认的问法进行适配，不会把所有相似题直接当成同一道题。
- 识别全程在本机完成，不需要账号登录或联网查答案，不上传截图，也不自动保存游戏截图。
- 若程序启动失败，会尝试在程序旁边生成“启动错误.txt”，可用于排查。
