# 🎮 XG助手 - 《造梦西游4手游》自动刷本工具

欢迎使用 **XG助手**！🚀 这是一款专为《造梦西游4手游》设计的自动化助手工具，旨在帮助玩家释放双手，高效完成日常刷副本的任务！🔥

无论是为了收集资源、提升等级，还是完成“肝帝活动”，XG助手都能成为您的得力助手。

---

## 🌟 项目特性

* ⚔️ **全自动副本战斗**：从进本到自动战斗，全流程自动化，无需人工干预。
* 🎯 **精准视觉识别**：基于像素和几何特征的对齐识别算法，对副本按钮、怪物、角色位置识别精准。
* 💻 **后台挂机支持**：特别优化，支持模拟器窗口置于后台运行。
* 擬 **拟人化防封**：模拟真人的操作轨迹、过冲回拉以及停顿时间，降低账号风险。
* 🗺️ **副本覆盖说明**：
  * ✅ 支持绝大多数普通副本。
  * ❌ **暂不支持**：特殊地形关卡（如需跳跃解谜的复杂地形）、多人模式。

## 🛠️ 环境配置 (非常重要! 必读! 🚨)

为了确保助手能 100% 成功运行，请务必**严格按照以下要求**配置您的运行环境：

### 🖥️ 1. 模拟器需求
* 本助手 **仅支持通过 [雷电模拟器](https://www.ldmnq.com/)** 运行。

### 📐 2. 模拟器分辨率
* 请进入模拟器的 **设置 -> 显示 -> 分辨率设置**。
* 务必将分辨率手动设置为：**1920 * 1080** (即默认的宽屏模式)。

### 🎮 3. 游戏操作设置
* 脚本运行前，请务必进入游戏的 **系统设置 -> 操作设置**，选择 **模式一**。

### 💻 4. 后台挂机限制
* 助手支持模拟器后台运行。
* **⚠️ 注意：请勿将模拟器窗口直接【最小化】（即完全缩到任务栏）。**
* **正确做法：** 您可以将雷电模拟器窗口放置在屏幕任何位置，然后被其他窗口（例如浏览器、工作软件）**覆盖**，但不能完全收起，否则识别算法将无法获取画面。

### 🖱️ 5. 鼠标控制
* 脚本运行时，**请勿**将鼠标光标放在雷电模拟器窗口内。
* 鼠标在窗口内可能会干扰虚拟鼠标按键，导致脚本卡死。

## 🚀 快速上手

您可以通过以下两种方式获取并运行助手：

### 📦 方式A：下载预编译版本 (适合普通玩家/推荐)

1. 前往本项目的 **[Releases](../../releases)** 页面。
2. 下载最新的预编译压缩包：`XG助手.zip`。
3. 解压下载的文件。
4. 运行模拟器和游戏，按上述配置调整模拟器。
5. 双击解压文件夹内的 `XG助手.exe` (或主程序) 即可运行。

### 💻 方式B：通过Git克隆仓库 (适合开发者)

如果您是开发者，想要自定义或修改脚本，可以通过克隆仓库运行：

1. **克隆仓库：**
   打开您的终端（Terminal / CMD / PowerShell），运行以下命令：
   ```bash
   git clone https://github.com/Deoeamay/XG_Assistant.git
   ```

2. **环境一键安装：**
   建议先安装 CPU 版 Torch（体积小、运行快），再安装其他依赖：
   ```bash
   # 安装 CPU 版 Torch
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
   
   # 安装其余依赖
   pip install -r requirements.txt
   ```

3. **运行项目：**
   直接运行主脚本：
   ```bash
   python main.py
   ```
